# Troubleshooting

## `OPENAI_API_KEY` missing

Set the variable in your shell or `.env` file and restart the process.

## `mcp` import error

Install the dependencies from `requirements.txt` inside the project virtual environment.

## Empty document results

Make sure `docs/` contains `.md` files with content and that the files are not empty.

## GitHub About box is empty

The About box is managed in GitHub repository settings. It needs a description, website, and topics to be set manually or via authenticated repo settings changes.
